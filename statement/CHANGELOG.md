# Changelog - Statement Microservice

## [1.0.0] - 2026-04-15

### Добавлено

#### Инициализация проекта

- Создание Spring Boot 3.4.4 приложения
- Модульная структура проекта с модулем `statement`

#### DTO объекты

- `LoanStatementRequestDto` - запрос на предварительный расчет
- `LoanOfferDto` - кредитное предложение с условиями
- `HttpErrorInternalServiceResponse` - ответ с ошибкой внутреннего сервиса

#### API Endpoints

- `POST /api/v1/statement - прескоринг и расчет кредитных предложений
- `POST /api/v1/statement/offer - Выбор кредитного предложения

#### Бизнес-логика

- **Прескоринг (StatementService):**
    - Валидация входных данных через аннотации `@Valid`
    - Кастомный валидатор `@Adult` для проверки совершеннолетия
    - Передача запроса в МС Deal без модификации
    - Логирование всех этапов обработки

- **Выбор предложения (StatementService):**
    - Валидация входного DTO
    - Передача выбранного предложения в МС Deal
    - Логирование результата

#### Интеграция с микросервисами

- **DealClientService** - REST клиент для взаимодействия с МС Сделка:
    - `calculateOfPossibleLoanTerms` - Расчет возможных условий кредита
    - `selectOffer` - Выбор одного из кредитных предложений

#### Документация

- Swagger/OpenAPI документация для всех endpoints
- Аннотации `@Schema` для всех DTO
- Примеры ответов для различных HTTP статусов (200, 400, 404, 500, 502)

#### Логирование

- INFO уровень для входящих запросов и результатов
- DEBUG уровень для промежуточных операций
- `LoggingInterceptor` для логирования всех HTTP запросов
- `LoggingInternalInterceptor` для логирования запросов с другими модулями

#### Обработка ошибок

- `GlobalExceptionHandler` с перехватом всех исключений
- Кастомные исключения: `InternalServiceException`
- Корректные HTTP статусы для различных ошибок

#### Тестирование

- **Unit-тесты:**
    - `StatementServiceTest` - тестирование логики работы с заявками
    - Покрытие > 90% для сервисов

- **Интеграционные тесты:**
    - `DealControllerTest` - тестирование всех endpoints

#### Валидация

- Аннотации `@Valid` на всех входных DTO
- Кастомные валидаторы для даты рождения
- Паттерны для email, паспортных данных, номера счета

### Зависимости

- Spring Boot: 3.4.4
- Java: 21
- Lombok: 1.18.36
- Springdoc OpenAPI: 2.8.5
