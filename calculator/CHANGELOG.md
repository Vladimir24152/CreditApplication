# Changelog

## [1.0.0] - 2024-03-12

### Добавлено
- Инициализация Spring Boot приложения calculator
- Базовая структура проекта согласно требованиям
- DTO объекты:
  - `LoanStatementRequestDto` - запрос на расчет предложений
  - `LoanOfferDto` - кредитное предложение
  - `ScoringDataDto` - данные для скоринга
  - `CreditDto` - полный расчет кредита
  - `EmploymentDto` - информация о занятости
  - `PaymentScheduleElementDto` - элемент графика платежей

### Реализовано
- **API Endpoints:**
  - `POST /calculator/offers` - расчет кредитных предложений
  - `POST /calculator/calc` - полный расчет кредита

- **Бизнес-логика:**
  - Прескоринг заявки с валидацией персональных данных
  - Генерация 4 кредитных предложений с комбинациями страховки и зарплатного клиента
  - Расчет процентных ставок с учетом скидок и надбавок
  - Скоринг клиента по полным данным
  - Расчет аннуитетных платежей
  - Формирование графика платежей
  - Расчет полной стоимости кредита (ПСК)

- **Скоринг:**
  - Проверка трудового статуса
  - Проверка должности
  - Проверка соотношения суммы кредита к доходу
  - Проверка семейного положения
  - Проверка возраста и пола
  - Проверка трудового стажа

- **Конфигурация:**
  - `LoanCalculatorProperties` - properties для настройки параметров
  - Поддержка всех параметров через application.yml

- **Документация:**
  - Swagger/OpenAPI документация всех endpoints
  - Аннотации `@Schema` для всех DTO

- **Логирование:**
  - INFO уровень для входных/выходных данных
  - DEBUG уровень для промежуточных расчетов

- **Тестирование:**
  - Unit-тесты для `LoanOfferService` (покрытие >90%)
  - Unit-тесты для `CreditCalculationService` (покрытие >90%)
  - Unit-тесты для `CalculateCreditUtil`
  - Использование Mockito для создания заглушек

- **Обработка ошибок:**
  - `NotValidBirthDateException` - неверная дата рождения
  - `ScoringFailedException` - отказ по скорингу
  - `GlobalExceptionHandler` с правильными HTTP статусами
