# Deal Service Microservice

Микросервис для управления кредитными заявками, клиентами и кредитными договорами.

## Описание

Deal Service отвечает за:
- Создание и управление кредитными заявками
- Сохранение данных клиента
- Взаимодействие с МС Калькулятор для расчета кредитных предложений
- Формирование кредитных договоров
- Управление статусами заявок и кредитов

## Архитектура

Микросервис входит в состав системы кредитования и взаимодействует с:
- **МС Калькулятор** - получение кредитных предложений и полного расчета
- **PostgreSQL** - хранение данных клиентов, заявок и кредитов

## Технологический стек

- Java 21
- Spring Boot 3.4.4
- Spring Data JPA
- PostgreSQL
- Lombok
- MapStruct
- Swagger/OpenAPI 3.0 (springdoc)
- JUnit 5, Mockito, Testcontainers
